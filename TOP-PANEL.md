# Customize the GNOME Top Panel

A step-by-step guide to achieving the translucent, blurred GNOME top panel shown in my Fedora rice.

## Requirements

- Blur my Shell
- Just Perfection
- Tasks in Panel
- ArcMenu (for the Fedora icon)

## 1. Install and Configure Extensions

Install the extensions above and adjust their settings using the screenshots below.

> **Note:** I use Blur my Shell v72 because recent updates caused issues with my setup. I'm using GNOME 50, but compatibility may vary depending on your GNOME and extension versions.
