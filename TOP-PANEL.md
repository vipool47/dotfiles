# Customize the GNOME Top Panel

A step-by-step guide to achieving the translucent, blurred GNOME top panel shown in my Fedora rice.

## Requirements

- **Blur my Shell** - panel transparency and blur
- **Just Perfection** - panel customization
- **Tasks in Panel** - window and application buttons 
- **ArcMenu** - fedora icon (optional)

## 1. Install and Configure Extensions

Install the extensions listed above and adjust their settings using the screenshots in this guide.

For reference : this configuration was tested on Fedora 44 with GNOME 50 and Blur my Shell v76. 

## 2. Configure Blur my Shell

Open Blur my Shell preferences and follow the settings shown below.

![Blur my Shell settings 1](screenshots/toppanel/blurmyshell1.png)

Make sure the background style is set to **Contrasted**. This provides the translucent, blurred effect used by the top panel.
